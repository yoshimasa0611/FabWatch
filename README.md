# FabWatch — 設備ログの異常検知と3D点検ロボット

Physical AI応用1の最終課題。目的は、AIによる異常度の推定をロボットの点検順序へ反映し、固定巡回と比べて初回異常点検時間と移動距離がどう変化するかを調べること。8台の模擬設備について温度・振動・消費電力のログを作成し、Isolation Forestの異常スコアを使って点検順を決めた。固定順（EQ01からEQ08）とスコア優先順の2通りで巡回させた。

## 工夫した点

- 学習・閾値設定・最終評価を別データで実施した。
- 機械学習の異常スコアを点検順序へ接続した。
- 初回点検時間の短縮だけでなく、移動距離の増加というトレードオフも定量評価した。
- VTKの立体形状・照明・カメラで3D可視化した。ただし走行は運動学モデルであり物理エンジンではない。

## 実装内容

1. 正常ログでIsolation Forestを学習。別の正常40条件で閾値を設定。
2. 学習・閾値設定とは別の60条件（計480設備窓）で異常検知を評価。
3. AIで決定した点検順、または設備番号順に従って、A*探索で経路を生成。
4. 差動二輪の簡略運動モデルで左右の車輪速度を計算し、設備前で停止して点検。
5. **VTK（Visualization Toolkit）で作成した本物の3Dオブジェクト**（床、設備、通路、ロボット本体、車輪）を透視投影カメラと照明で描画。センサー光線も表示する。
6. 動画・PDF・CSVを出力し、固定方式とAI方式を比較。

## 動画の3D表現について

以前の等角投影による2D図形とは異なり、今回の映像はVTKの3D座標、立体メッシュ、照明、カメラで実際に描画したもの。移動には**差動二輪の運動学モデル**を使用しているため、**PyBulletのような物理エンジンによる剛体運動、タイヤの摩擦、衝突時の応答を再現しているわけではない**。距離センサーは3D空間中の水平レイと設備の直方体の交差距離を簡略計算したもので、走行制御に使っていない。AIは車輪制御ではなく点検順の決定に用いている。

また、工場レイアウト・異常ログは人工データであり、実際の半導体製造現場を再現したものではない。

## 結果（人工データ・計画経路の評価）

| 指標 | 結果 |
|---|---:|
| 異常検知 Precision | 0.895 |
| Recall | 1.000 |
| F1 | 0.944 |
| 初回異常設備点検時間・固定方式 | 26.3秒 |
| 初回異常設備点検時間・AI優先方式 | 14.7秒 |
| 平均計画移動距離・固定方式 | 19.8m |
| 平均計画移動距離・AI優先方式 | 39.3m |

60条件中42条件でAI方式の点検完了時間が早かったが、総移動距離は長かった。**これらの数値はA*で生成した計画経路と一定の走行速度・点検時間を仮定した比較結果**であり、動画の3Dロボットの実機計測値ではない。

## Colabでの実行

`FabWatch_Colab.ipynb` を開き、CPUランタイムで実行。インストールセルで `vtk` や `fonts-noto-cjk` を導入し、コード・データ・3D本編MP4・PDFを生成する。PDFの指定ファイル名にはOmniCampusアカウント名を使用する。コードやレポート本文、動画には氏名・所属・メールアドレスなどを記載しない。`OMNI_ACCOUNT_ID` 環境変数を自分の環境で設定すればPDFファイル名に反映される（公開コードには値を保存しない）。

**OP/ED** は使用許諾がある場合だけ `assets/OP.mp4`, `assets/ED.mp4` に置いて結合する。講義配布動画はGitHubに含めない。

## ローカルでの実行

Python 3.11以降、`ffmpeg` と日本語フォント `Noto Sans CJK` が必要。講義提供のOP・EDを公開リポジトリに入れないでください。

```bash
python -m pip install -r requirements.txt
python src/build_submission.py
python tests/test_pipeline.py
```

## Colab再実行時の注意

最新ノートブックでは、異常検知の評価CSVとグラフ画像を生成してから動画を作成します。再開時は、完成済みの動画パートを検証して再利用します。動画生成はColabのCPU環境で長くかかる場合があります。

## 公開ノートブックと元の実行結果について

このリポジトリの `FabWatch_Colab.ipynb` は、Colabで最終実行したノートブックのコードを保持しつつ、公開用に実行結果と実行履歴メタデータを削除したものです。
第6節は、利用許諾があるOP・EDファイルを実行時にアップロードして結合する手順です。OP・ED素材そのものは同梱していません。

`requirements.txt` はPython依存関係を記載していますが、ローカル実行時は別途FFmpegと日本語フォントの用意が必要です。
